# Archive

Historical material, kept for the record and not published on the docs
site. Nothing here describes lirk as it is now; for that, see the
[user docs](https://socitt.github.io/lirk/) or, for maintainers,
[`docs/dev/`](../dev/).

- **`v1-docs/`** — the README and user docs as they stood at v1.0.0
  (2026-11-21), before they were rewritten around how to use lirk. They
  tell the origin story in full: the `signal: hangup` bug in Please on
  iSH-AOK, the process-model constraints it led to, and the v1
  stability criteria.
- **`assessments/`, `reviews/`** — dogfooding reports and reviews from
  lirk's first real repos (July 2026), the evidence behind the v1
  criteria.
- **`ACTIVE_SESSION.md`** — a working log from an early development
  session.
